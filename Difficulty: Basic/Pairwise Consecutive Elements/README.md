<h2><a href="https://www.geeksforgeeks.org/problems/pairwise-consecutive-elements/1">Pairwise Consecutive Elements</a></h2><h3>Difficulty Level : Difficulty: Basic</h3><hr><div class="problems_problem_content__Xm_eO" style="--text-color: var(--problem-text-color);"><p class="PDq2pG_selectionAnchorContainer" data-start="399" data-end="500"><span style="font-size: 14pt;">Given a stack of <strong>n</strong> integers, determine whether its elements are <strong data-start="475" data-end="499">pairwise consecutive</strong>. </span><span style="font-size: 14pt;">Starting from the top of the stack, group the elements into consecutive pairs. </span></p>
<p class="PDq2pG_selectionAnchorContainer" data-start="399" data-end="500"><span style="font-size: 14pt;">A pair is said to be pairwise consecutive if the absolute difference between the two elements is exactly <strong data-start="693" data-end="698">1</strong>. </span></p>
<p class="PDq2pG_selectionAnchorContainer" data-start="399" data-end="500"><span style="font-size: 14pt;">The two elements in a pair may be in either increasing or decreasing order. </span><span style="font-size: 14pt;">If the stack contains an odd number of elements, the topmost element is not included in any pair. </span></p>
<p class="PDq2pG_selectionAnchorContainer" data-start="399" data-end="500"><span style="font-size: 14pt;">Return <strong data-start="889" data-end="897">true</strong> if every pair in the stack is pairwise consecutive. Otherwise, return <strong data-start="968" data-end="977">false</strong>.</span></p>
<p data-start="983" data-end="992"><span style="font-size: 14pt;"><strong data-start="983" data-end="992">Note: </strong></span><span style="font-size: 14pt; font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, Oxygen, Ubuntu, Cantarell, 'Open Sans', 'Helvetica Neue', sans-serif;">The original contents and order of the stack must remain unchanged after the function returns.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:<br></strong></span></p>
<pre><span style="font-size: 18px;"><strong>Input</strong>: stack = [4, 5, -2, -3, 11, 10, 5, 6, 20]
<strong>Output</strong>: true
<strong>Explanation</strong>: </span><span style="font-size: 14pt;">The rightmost element represents the top of the stack. Since the stack contains an odd number of elements, the top element (20) is ignored. The remaining pairs, starting from the top, are (6, 5), (10, 11), (-3, -2), and (5, 4). The absolute difference between the elements of each pair is 1. Therefore, the answer is true.</span></pre>
<pre><span style="font-size: 18px;"><span style="font-size: 18px;"><strong>Input</strong>: stack = [4, 6, 7, 8, 10, 11]
<strong>Output</strong>: false
<strong>Explanation</strong>: The top of the stack is 11. The pairs formed from the top are (11, 10), (8, 7), and (6, 4). While the first two pairs are consecutive, the pair (6, 4) is not. Therefore, the answer is false.</span></span></pre></div><br><p><span style=font-size:18px><strong>Topic Tags : </strong><br><code>Stack</code>&nbsp;
